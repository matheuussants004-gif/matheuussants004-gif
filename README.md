### 👨‍💻 Sobre Mim

Desenvolvedor focado na criação de soluções e plugins para servidores de Minecraft (Spigot, Paper e Velocity). Desenvolvo sistemas orientados a desempenho, organização de código e integração com bancos de dados.

- 🎮 **Foco:** Plugins para Spigot/Paper, Minigames, Sistemas de Economia e Mecânicas de Combate.
- ⚡ **Prioridades:** Otimização de código, execução assíncrona e estabilidade (20.0 TPS).
- 💬 **Discord:** `@segundacontattk`
